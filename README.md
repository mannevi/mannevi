## 🚀 Projects

### 🚕 NYC Rideshare Analytics Pipeline
> PySpark · Snowflake · dbt · AWS S3 · Apache Airflow · Python · Parquet

- Engineered an end-to-end cloud data pipeline processing **19.8M real Uber/Lyft trip records**
- Ingested raw NYC TLC trip data and loaded into **AWS S3** as the data lake source
- Distributed transformation with **PySpark** — null handling, schema enforcement, deduplication, feature engineering
- Orchestrated 6-task **Apache Airflow DAG** with full dependency management and failure alerting
- Modeled clean data in **Snowflake** using **dbt** — fact and dimension tables, incremental models
- Full pipeline runs in **under 8 minutes** end-to-end on 19.8M records
- Exported analytics-ready **Parquet** files for downstream BI consumption

🔗 [View Project](https://github.com/mannevi/nyc-rideshare-pipeline)
